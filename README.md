## `03 / AI.Engineering`

No **Agenda Aê**, a responsabilidade é dividida por domínio: um agente atua sobre back-end, schema e motor de automação; outro sobre UI e design system. Mudanças maiores começam como especificação escrita, avançam por fases e passam por revisão antes do merge.

```text
spec → context → agent ownership → implementation → review → PR → observability
```

Mantenho também um vault de pesquisa em IA aplicada ao desenvolvimento com **189 fontes primárias distribuídas em 11 eixos**, incluindo RAG, segurança, geração de código, testes, confiabilidade, agentes, dados, fatores humanos, requisitos, contexto e produtividade.

Antes de trabalhar com automação e agentes, atuei em operação crítica como **NOC e Analista de Sistemas**, monitorando ambientes de produção 24/7 com Zabbix, Elastic, Grafana e Datadog, além de Active Directory e resposta a incidentes.
